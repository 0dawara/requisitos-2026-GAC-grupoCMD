# Sistema de Gestão de Ativos do CCT (GAC)

Repositório do Grupo CMD referente à atividade de Requisitos e Modelagem de Sistemas.

Este projeto visa modelar e documentar os requisitos para um **sistema de gestão de ativos**, controlando o inventário e locação de projetores, cabos, acessórios e chaves do Centro de Ciências Tecnológicas (CCT).

## Estrutura do Repositório

- [Requisitos/](Requisitos/) — Contém toda a documentação de engenharia de requisitos (Elicitação, Casos de Uso, Regras de Negócio e Requisitos Não Funcionais).
- [diagramas/](diagramas/) — Contém os modelos visuais e diagramas do projeto.
